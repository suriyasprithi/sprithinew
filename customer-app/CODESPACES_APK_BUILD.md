# SPRITHI Customer APK / AAB — build from scratch in GitHub Codespaces

End-to-end guide to produce a **signed APK** (sideload/testing) and a **signed AAB**
(Play Store) for the customer app, with **camera** (QR scanner) and **native share**
working, and **push notifications** (FCM) wired.

- App id: `com.epey.customer`  ·  App name: `SPRITHI`  ·  webDir: `out`
- The `android/` folder is **not** in git — it is regenerated by `cap add android`.
- Native share uses `@capacitor/share`; the QR scanner uses the WebView camera
  (`getUserMedia`), which needs the `CAMERA` permission in the manifest.

> After the first full setup you can **keep `android/`** and only re-run
> `npx cap sync android` for future web changes — you do **not** have to redo the
> manifest / gradle / keystore steps every time. Do the from-scratch flow below
> only for a clean rebuild.

---

## 0. One-time Codespaces environment (Java + Android SDK)

Codespaces (Ubuntu) has Node but **not** Java/Android SDK. Install them once per
Codespace:

```bash
# --- Java 21 (required by Capacitor 8 / Android Gradle Plugin) ---
sudo apt-get update
sudo apt-get install -y openjdk-21-jdk unzip
java -version          # should print 21.x

# --- Android SDK command-line tools ---
export ANDROID_HOME="$HOME/android-sdk"
mkdir -p "$ANDROID_HOME/cmdline-tools"
cd "$ANDROID_HOME/cmdline-tools"
curl -L -o tools.zip https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
unzip -q tools.zip
mv cmdline-tools latest          # sdkmanager expects cmdline-tools/latest/
rm tools.zip

# --- Persist env for every new terminal ---
cat >> ~/.bashrc <<'EOF'
export ANDROID_HOME="$HOME/android-sdk"
export JAVA_HOME="/usr/lib/jvm/java-21-openjdk-amd64"
export PATH="$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/build-tools/36.0.0"
EOF
source ~/.bashrc

# --- Accept licenses + install SDK packages (compileSdk 36) ---
yes | sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-36" "build-tools;36.0.0"
```

## 1. Install JS deps + set the production API URL

```bash
cd /workspaces/<repo>/customer-app     # adjust to your path
npm install                            # pulls @capacitor/share, push, jsqr, …
```

The API base is **baked in at build time** (`NEXT_PUBLIC_API_URL`). Make sure
`customer-app/.env.production` points at the live backend:

```bash
# customer-app/.env.production
NEXT_PUBLIC_API_URL=https://app.sprithi.com
NEXT_PUBLIC_REFERRAL_DOMAIN=https://app.sprithi.com
```

## 2. Build the web bundle for the APK (basePath empty) + add Android

`CAPACITOR_BUILD=1` makes `next.config.ts` use an **empty** basePath (the APK loads
from the app root, not `/customer`). The `cap:add:android` script already sets it.

```bash
# clean any previous android project for a true from-scratch build
rm -rf android out .next

npm run cap:add:android
# = cross-env CAPACITOR_BUILD=1 npm run build  &&  cap add android
```

You now have a fresh `android/` project with the web assets copied in.

---

## 3. Camera permission (QR scanner)

Edit **`android/app/src/main/AndroidManifest.xml`** — add these lines just inside
`<manifest>`, above `<application>`:

```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-feature android:name="android.hardware.camera" android:required="false" />
```

`INTERNET` and `POST_NOTIFICATIONS` are added automatically by Capacitor + the push
plugin. The WebView grants the camera prompt once the runtime permission is allowed.

---

## 4. Push notifications — google-services.json (FCM)

Push is the core requirement and needs Firebase for package `com.epey.customer`.

1. Put your Firebase **`google-services.json`** at:
   ```
   android/app/google-services.json
   ```
2. Add the Google services Gradle plugin:

   **`android/build.gradle`** (project-level) → inside `buildscript { dependencies { … } }`:
   ```gradle
   classpath 'com.google.gms:google-services:4.4.2'
   ```

   **`android/app/build.gradle`** → at the very bottom:
   ```gradle
   apply plugin: 'com.google.gms.google-services'
   ```

## 5. The release keystore

> ⚠️ Play Store updates must be signed with the **same** keystore that signed the
> first upload. Never commit it to git (it is a secret — `.keystore` / `.jks` are
> already gitignored). Back up the file **and** its passwords; losing them means
> you can never update the app under the same listing.

### Option A — you already have a keystore (use THIS for an existing app)

Copy your existing keystore into the app folder and note its details:

```bash
cd customer-app
cp /path/to/your-existing.keystore ./sprithi-release.keystore

# Find the alias inside it (and confirm the password works):
keytool -list -v -keystore ./sprithi-release.keystore
#   look for "Alias name: <alias>"
```

Use that **file name**, **alias**, and the **store/key passwords you already have**
in step 6. Do **not** generate a new one — a different keystore can't update the
same Play listing.

### Option B — brand-new app, no keystore yet

```bash
cd customer-app
keytool -genkeypair -v \
  -keystore sprithi-release.keystore \
  -alias sprithi \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -dname "CN=SPRITHI, OU=Mobile, O=SPRITHI, L=Chennai, ST=TamilNadu, C=IN"
# enter and remember the store password + key password when prompted
```

## 6. Wire the keystore into Gradle signing

Create **`android/keystore.properties`** (do NOT commit this):

```properties
# keyAlias + the two passwords must match YOUR keystore from step 5
# (run `keytool -list -v -keystore sprithi-release.keystore` to confirm the alias)
storeFile=../../sprithi-release.keystore
storePassword=YOUR_STORE_PASSWORD
keyAlias=sprithi
keyPassword=YOUR_KEY_PASSWORD
```

Edit **`android/app/build.gradle`** — inside `android { … }` add the signing config
and use it for `release`:

```gradle
// near the top of android/app/build.gradle, before `android {`
def keystoreProps = new Properties()
def keystoreFile = rootProject.file("keystore.properties")
if (keystoreFile.exists()) { keystoreFile.withInputStream { keystoreProps.load(it) } }

android {
    // … existing config …

    signingConfigs {
        release {
            if (keystoreFile.exists()) {
                storeFile file(keystoreProps['storeFile'])
                storePassword keystoreProps['storePassword']
                keyAlias keystoreProps['keyAlias']
                keyPassword keystoreProps['keyPassword']
            }
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
        }
    }
}
```

## 7. Sync plugins + build

```bash
cd customer-app
npx cap sync android          # registers @capacitor/share, copies web, etc.

cd android
chmod +x gradlew

# --- Signed APK (sideload / direct install) ---
./gradlew assembleRelease
#  → android/app/build/outputs/apk/release/app-release.apk

# --- Signed AAB (upload to Google Play Console) ---
./gradlew bundleRelease
#  → android/app/build/outputs/bundle/release/app-release.aab
```

---

## 8. Verify + ship

```bash
# Confirm the APK is signed
apksigner verify --print-certs \
  app/build/outputs/apk/release/app-release.apk
```

- **APK** → in the Codespaces file explorer, right-click
  `android/app/build/outputs/apk/release/app-release.apk` → **Download**, then
  install on the phone (enable "install unknown apps").
- **AAB** → download `app-release.aab` and upload it to the Play Console.

## Re-build later (web changes only — keep android/)

```bash
cd customer-app
git pull
npm install
npx cap sync android          # rebuilds web (CAPACITOR_BUILD via cap:sync) + copies it
cd android && ./gradlew assembleRelease   # or bundleRelease
```

## Quick troubleshooting

| Symptom | Fix |
|---|---|
| White screen in APK | Built without `CAPACITOR_BUILD=1` → basePath `/customer`. Rebuild with `npm run cap:sync`. |
| Camera doesn't open | `CAMERA` permission missing from AndroidManifest (step 3). |
| Share opens "copied" only | `@capacitor/share` not synced → run `npx cap sync android`. |
| No push notifications | `google-services.json` missing or the google-services gradle plugin not applied (step 4). |
| `SDK location not found` | `export ANDROID_HOME=$HOME/android-sdk` not set in this terminal (`source ~/.bashrc`). |
| `licences not accepted` | `yes \| sdkmanager --licenses`. |
