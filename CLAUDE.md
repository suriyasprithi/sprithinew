# Project Rules

## Scope
- This is a **simple website** that will be converted into an **Android and iOS APK/app**.
- **Do NOT add more and more features.** Keep everything minimal.
- Only build/change what is explicitly requested. No extra features, no scope creep.

## Core Requirement
- The client's **main requirement** is **push notifications** working inside the APK (Android + iOS).
- Push notifications must function correctly when the website is wrapped as a mobile app.

## Working Style
- Discuss first, then code.
- Keep the website lightweight and mobile-app friendly.
- Avoid unnecessary dependencies, libraries, or complexity.

## Execution Rules
- Whatever details the user provides must be **fully executed** — but only with **basic/minimal functionality**.
- **Do not expand or enhance** anything unless the user explicitly says so.
- Before writing any code, **always create a complete plan first**.
- **Wait for user verification/approval** of the plan before starting implementation.
- Only after approval, begin coding.
